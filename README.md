# 🔮 Ramalkan Akibatnya!

Game pendidikan interaktif berasaskan web untuk **Pendidikan Moral Tahun 5**.

## Fokus pembelajaran
- Standard Kandungan 14.0: Amalan Toleransi Dalam Hidup Bermasyarakat
- SP 14.3: Membuat justifikasi kesan pengabaian toleransi
- SP 14.4: Mengekspresikan perasaan berkaitan toleransi
- SP 14.5: Mengamalkan sikap bertoleransi

## Ciri utama
- 6 situasi kehidupan bermasyarakat
- Ramalan akibat + maklum balas pemikiran
- Komponen utama: **“Saya memilih ___ kerana ___.”**
- Bantuan jawapan untuk murid yang kurang mahir menulis
- Pilihan perasaan
- Pemilihan tindakan bertoleransi
- 18 bintang maksimum
- Video simulasi HTML/CSS
- Mod Guru
- Bunyi ringan menggunakan Web Audio API
- Responsive untuk komputer, tablet, iPad dan telefon
- Tiada backend, login, API key atau iklan

## Fail
- `index.html`
- `style.css`
- `script.js`

Semua data situasi disimpan dalam array `situations` di dalam `script.js` dan mudah diedit.
